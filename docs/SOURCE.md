# Source provenance

The evaluation code, seven-case slug fixture, and legacy schema came from earlier
evaluation research by the project author. The source package contains no research
results, machine inventory, credentials, model weights, or model output. The
shipping-notice and investigation fixtures use synthetic data. Toolkit-owned
material is licensed under Apache-2.0.

The legacy schema keeps its original namespace so older result files still validate.
It does not connect to another service. See
[THIRD_PARTY](../THIRD_PARTY.md) for dependency and fixture licensing.
