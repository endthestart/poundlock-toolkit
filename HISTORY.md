# History

Poundlock Toolkit started in September 2026 as the evaluation half of a private
project for running coding agents on local models. It was extracted from earlier
evaluation research on 13 September 2026 and released internally as 0.1.0 through
0.3.1; [CHANGELOG.md](CHANGELOG.md) covers those releases.

That history (65 commits, all by one author) referenced private infrastructure, so
this repository starts at 0.4.0 with a single commit. Development continues here.
