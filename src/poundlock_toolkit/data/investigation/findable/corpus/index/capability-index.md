# Capability index

This index records, for each internal requirement code, the one module (if any) that is on record as satisfying it. A requirement with no row here has no module on record.

REQ-3: CHARLIE-8 -- atomic multi-writer replace, no append.
REQ-7: EPSILON-9 -- coordinates append across multiple writer handles.
REQ-12: BRAVO-5 -- crash-safe append, single writer only.
